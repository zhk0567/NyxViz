## 总览

```
docs/
├── submission/     ← 上交 Word、本解读手册、代表图
├── competition/    ← 赛题待办、录屏旁白与操作
├── report/         ← 四题 Markdown 文字源
├── figures/        ← 全部 PNG/GIF 配图
├── showcase/       ← 单文件离线 HTML（生成物）
├── TOOLS_USAGE.md  ← 技术栈清单
└── README.md       ← 文档目录入口
```

---

## docs/submission/

| 文件 | 用途 | 何时改 |
|------|------|--------|
| **NyxViz.docx** / **NyxViz_作品说明文档.docx** | 作品说明正文 | 改 `work_doc_content.py` 后 `npm run export-docx` |
| **Nyx_answerSheet_filled.docx** | 官方四题答卷 | 改 `docs/report/*.md` + `team.json` 后 `fill-answer-sheet` |
| **NyxViz_作品说明文档.pdf** | PDF 备份 | `npm run export-pdf` |
| **submission_representative.jpg** | 代表图 &lt;20MB | 由 poster 图导出 |
| **SUBMISSION_PACK.txt** | 提交清单 | `submission-pack` 自动更新 |
| **NyxViz_零基础完全解读.md** | 本手册索引 | 人工维护 |
| **guide/** | 分章解读（00–10） | 人工维护 |
| **_docx_live_extract.txt** | docx 文本抽取（核对用） | 抽取脚本 |
| **DOCX_TEXT_REVIEW.md** | 四题图号核对笔记 | 改图后核对 |

## docs/competition/

| 文件 | 用途 |
|------|------|
| **TASKLIST.md** | 截止日期、M/V 待办、提交自检 |
| **VIDEO_NARRATION_TTS.txt** | 录屏旁白 11 行（TTS 输入） |
| **VIDEO_NARRATION.md** | 旁白 + scene 对照 + 时间轴 |
| **VIDEO_NARRATION.srt** | 字幕（`generate_video_srt.py` 生成） |
| **VIDEO_SCRIPT.md** | OBS 设置、录屏 URL、录前检查 |
| **VIDEO_RECORDING_OPS.md** | 旁白说到哪句指哪里/点哪里 |
| **ABSTRACT_100.txt** | 提交用 100 字摘要 |
| **LAYOUT_SPEC.md** | 3840×6480 长图布局规格 |
| **WIREFRAME_CHECKLIST.md** | 线框检查清单 |
| **team.json** | 队名成员（勿提交 secrets） |

## docs/report/

| 文件 | 用途 |
|------|------|

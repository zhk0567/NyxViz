## 赛题给了什么数据

### 一句话

官方给了一个**小型宇宙模拟**在 **100 个时间点**上的**气体密度快照**：每个时间点是一个 **128×128×128** 的立方体网格，每个格子里有一个数字——**气体密度 ρ**。

### 稍微细一点

| 项目 | 含义 |
|------|------|
| **Nyx** | 一种宇宙学流体模拟程序，在超级计算机上算「宇宙里气体怎么动」 |
| **128³** | 边长 128 个格子，共 128×128×128 = **2,097,152** 个体素（小立方体） |
| **100 步** | 时间步 t = 0, 1, 2, …, 99（不是现实年份，是模拟里的「第几步」） |
| **文件** | `Nyx/0000.dat` … `Nyx/0099.dat`，每个约 8 MB |
| **格式** | 小端 float32，无文件头；存储顺序 **z 最快 → y → x** |

### 物理上在模拟什么

- 宇宙早期，气体几乎**均匀**，只有微小涨落。  
- 在**引力**作用下，物质逐渐**成团**：稀的地方更稀（**void 空洞**），密的地方连成**丝（filament）**和**节点（node）**——这就是**宇宙网（cosmic web）**。  
- 本数据是其中一块 **128³ 子体积**里的**重子气体**（普通物质气体），**不包含暗物质粒子**。

更多天文背景见 Word §5.4–5.6 与 [02 词典 · IGM / void / filament](./02-专业名词词典.md)。

## 赛题四个任务分别问什么

官方要求从**可视化与可视分析**角度完成四题（答卷每题 ≤800 字）。白话版如下：

### 任务一：体数据渲染与密度演化

**问**：能不能把 3D 密度场**画出来**，让人看见 void—filament—node **随时间怎么变**？  
**答**：用 **vtk.js 体渲染**，展示 t=0/25/50/75/99 五帧，说明宇宙网从「雾状」到「丝状清晰」。

### 任务二：宇宙密度演化规律归纳

**问**：除了肉眼看图，**100 步统计**上有什么规律？可视化对宇宙学分析**有什么用**？  
**答**：用 `timeline.json` 的 σ、p99−p01、void 占比等曲线归纳**团块化、两极化**；用案例 A/B/C 说明「百步曲线防挑帧」「刷选连空间」。

### 任务三：时序密度对数直方图统计

**问**：用**对数直方图**量化密度分布怎么漂移？  
**答**：128 bin log 直方图，说明 void 扩大、p50 下移、右尾抬高等。

### 任务四：相空间交互刷选可视分析

**问**：能不能在**直方图上刷选**密度区间，并和**3D 体渲染、2D 投影**联动？  
**答**：三栏仪表盘：Top 1% / 纤维带 / Bottom 1% 预设 + 拖拽框选，验证「统计尾区 = 空间 filament」。

## 本作品**刻意不做**的事（答辩要说清）

这些在 Word §5.4–5.6 有写，评委可能问：

| 不做 | 原因 |
|------|------|
| **AMR 多分辨率可视化** | 赛题只给了均匀 128³，没有细化层级元数据 |
| **暗物质场对比** | 数据包只有重子气体密度 |
| **真实 Lyα 森林谱线** | 未做辐射传输；只有密度列平均的**代理 PDF**（§5.5） |
| **红移 z / 宇宙学时间** | .dat 只有时间步索引 0…99 |
| **条带图与交互页体渲染完全一致** | 条带用 capture 专用 TF，交互页用全局 TF（见 [00 章](./00-阅读指南.md)） |

这不是缺陷，而是**在赛题数据边界内**做可视分析。

## 和「宇宙网诞生记」叙事的关系

作品叙事名 **「宇宙网诞生记」** 指：

1. **诞生**：t=0 近似均匀 IGM；  
2. **成形**：中间步 filament 连通；  
3. **定型**：t=99 可见 void—filament—node 拓扑；  
4. **证据**：统计曲线 + 刷选验证，而不只靠两帧截图。

叙事闭环详见 [03 章](./03-叙事逻辑与科学结论.md)。

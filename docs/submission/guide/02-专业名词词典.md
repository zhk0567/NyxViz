## 一、宇宙学与天文

### IGM（Intergalactic Medium，星系际介质）

- **人话**：星系与星系之间填充的稀薄气体，占宇宙普通物质很大一部分；本数据就是这块气体在模拟里的**密度场**。
- **在本作品里**：Word §0、§2；体渲染里「雾状」背景 mostly IGM。
- **相关**：`Nyx/*.dat` 重子气体密度。

### void / filament / node（空洞 / 纤维 / 节点）

- **人话**：宇宙网三种结构——**void** 极稀、**filament** 丝状连接、**node** 高密度结点（常对应 future 星系团）。
- **在本作品里**：§1 五帧体渲染叙事；录屏 task1-morph 指中栏结构。
- **相关**：体渲染 + Top 1% 刷选高亮 filament。

### 宇宙网（cosmic web）

- **人话**：void、filament、node 组成的整体拓扑；本作品标题「宇宙网诞生记」即讲它如何从无到有。
- **在本作品里**：全文主线；发现卡 01「宇宙网形成」。

### 重子气体（baryon gas）

- **人话**：由质子、中子组成的普通物质气体（相对暗物质而言）；赛题 .dat **只有**这一种场。
- **在本作品里**：Word §5.6 说明未含暗物质。
- **相关**：`timeline.json` → `dataScope.includedFields`

### 莱曼阿尔法森林（Lyα forest）

- **人话**：远处类星体光谱里一串 Lyα 吸收线，反映视线方向 IGM 密度涨落；Nyx 类模拟常用于研究 IGM。
- **在本作品里**：§5.5 **未做真实谱线**，只做 2000 条视线列平均密度的 PDF **代理**（图18–19）。
- **相关**：`validation_extended.json` → `lyalphaProxy`

### AMR（Adaptive Mesh Refinement，自适应网格细化）

- **人话**：模拟时在致密区自动加密网格，省算力又分辨细节；Nyx 本体支持 AMR。
- **在本作品里**：§5.4 明确**赛题数据已是均匀 128³ 抽取**，本作品不做 AMR 可视化。
- **相关**：无（数据边界说明）。

### 团块化（structure formation）

- **人话**：引力让均匀涨落长成团块、纤维的过程。
- **在本作品里**：σ +15.4%、p99−p01 +15.1% 的定量描述；§2 主证。

## 二、统计量

### ρ（rho，密度）

- **人话**：每个体素里的气体密度标量；本数据集全域约 **7.75–14.52**（log10 域常用 8.35–10.76 等分位）。
- **在本作品里**：色标「气体密度 ρ」；刷选区间 `ρ∈[min,max]`。
- **相关**：`.dat` 文件；`timesteps[t].mean` 等。

### σ（标准差，standard deviation）

- **人话**：全体 128³ 格密度相对均值的离散程度；**越大**说明「有的很稀、有的很密」分化越厉害。
- **在本作品里**：t=0 **0.4318** → t=99 **0.4983**，**+15.4%**；KPI 卡、图6、录屏 task2-evolution。
- **相关**：`timeline.json` → `timesteps[t].std`

### 均值（mean）

- **人话**：128³ 格密度的算术平均；随时间略降（质量重分配，非守恒展示重点）。
- **相关**：`timesteps[t].mean`（t=99 约 9.3187）

### p01 / p50 / p99 / p999（分位数）

- **人话**：把全部体素密度排序后，第 1%/50%/99%/99.9% 位置的值；**p99** 常作「Top 1% 阈值」。
- **在本作品里**：Top 1% 刷选 = ρ ≥ 该步 **p99**（t=99 为 **10.7601**）。
- **相关**：`timesteps[t].p01`, `.p50`, `.p99`, `.p999`

### p99 − p01（分位跨度 / span）

- **人话**：高密度尾与低密度尾拉开多远；**团块化**核心指标之一。
- **在本作品里**：2.098 → 2.414，**+15.1%**；录屏左栏 KPI「分位跨度」。
- **相关**：`storyMetrics` 计算；迷你趋势图 `metric: span`

### pp（percentage point，百分点）

- **人话**：绝对差。例如 10%→24.69% 是 **+14.69 pp**，不是「增长了 147%」。
- **在本作品里**：void 占比叙述；避免相对百分比误解。

### 偏度（skewness）

- **人话**：分布是否**右偏**（长尾拖向高密度）；辅助说明右尾，**不作主证**。
- **在本作品里**：t=0 **0.716** → t=99 **0.718**；图6 第四联、录屏 task2-evolution 右栏第四图。
- **相关**：`timesteps[t].skewness`

### 超额峰度（excess kurtosis，κ−3）

- **人话**：分布尾部「有多尖」；空间统计辅证之一。
- **在本作品里**：task2-spatial 四宫格之一；**不作团块化主证**。
- **相关**：`timesteps[t].excessKurtosis`

### Moran's I（莫兰指数）

- **人话**：空间上「相邻格子是否相似」；接近 1 表示强空间聚集。
- **在本作品里**：0.9276→0.9361；bootstrap 增量未达 2σ，**仅描述性**（§2、task2-spatial）。
- **相关**：`timesteps[t].moransI`

### ξ(r)（两点相关函数）

- **人话**：相距 r 的体素密度是否相关；宇宙学里常用。
- **在本作品里**：ξ(r=1) 0.855→0.871；宽图剖面 + bootstrap 带（图8、task2-spatial）。
- **相关**：`xiR1`, `xiProfile` in `validation_extended.json`

### bootstrap（自助法）

- **人话**：重复随机抽样估计「指标有多不确定」；本作品对 Moran's I / ξ 做子块抽样。
- **在本作品里**：「增量未达 2σ」= 不能声称显著变化；task2-spatial 右侧。
- **相关**：`tools/python/validation_suite.py`

### 体积占比 / 质量占比

- **人话**：满足某密度条件的体素占**格子数比例**（体积）vs 占**密度总和比例**（质量 proxy）。
- **在本作品里**：≥p99 **1.00% 体积、约 1.19% 质量**；发现卡 03、案例 B。
- **相关**：`tailMassAboveP99`, `massFractionAboveP99`

### void 分数（voidFractionBelowT0P10 / P01）

- **人话**：用 **t=0 时** p10（或 p01）作为固定阈值，看 t 步有多少体积比它还稀。
- **在本作品里**：p10 路径 10%→**24.69%**；p01 路径 1%→**6.18%**（task2-void、§3）。
- **相关**：`voidFractionBelowT0P10`, `voidFractionBelowT0P01`

### 召回率 / 精确率 / 误报率

- **人话**：刷选结果 vs「filament 亮脊代理」对比——召回=找全了吗，精确=选中的里有多少真是脊线。
- **在本作品里**：离线 **召回 100%**、**精确率 27.6%**（误报 72.4%）= 密度 Top 1% **包含**脊线但**更宽**；task4-validate。
- **相关**：`brush_validation.json`

### Jaccard 系数

- **人话**：两个集合重叠程度，0–1；用于分辨率粗化后脊线是否还在。
- **在本作品里**：64³ 粗化 Jaccard≈**0.65**（原点对齐）；8 组偏移均值 **0.544±0.076**（图5、§1）。

## 三、可视化

### 体渲染（volume rendering）

- **人话**：把 3D 密度体画成半透明「云」，看见内部结构；GPU 光线投射。
- **在本作品里**：中栏 `VolumeScene`；任务一核心。
- **相关**：`src/volume/VolumeScene.tsx`, vtk.js — **源码**：[10a](./10a-体渲染与VTK代码.md)

### 传递函数 / TF（Transfer Function）

- **人话**：规定「密度多少 → 什么颜色、多不透明」；宇宙学常用 **log10 域**。
- **在本作品里**：cosmic 预设；左栏 task1-tf 七级 **α** 阶梯；域 **8.346–10.760**（全局 p01–p99）。
- **相关**：`src/volume/transferFunction.ts`, `render_spec.json` — **源码**：[10a §transferFunction](./10a-体渲染与VTK代码.md)

### TF 增益 / Evolution Capture Profile

- **人话**：**仅 capture 条带截图**用：每帧微调 opacityScale、densityGain，让早期帧少雾、晚期帧亮丝——**不改体素密度**。
- **在本作品里**：Word 图4(c)；**交互页不用**。
- **相关**：`getEvolutionCaptureProfile` in renderSpec

### densityGain

- **人话**：平移 TF 控制点在 ρ 轴上的系数；负值压 IGM 雾感。
- **相关**：`render_spec.json`；录屏旁白 task1-tf 与 capture 区分

### opacityScale / α（alpha，不透明度）

- **人话**：整体透明度乘子；α 阶梯 0→0.95 让 filament 更亮、void 更透。
- **在本作品里**：task1-tf 左栏 7 处 alpha。

### Phong 光照 / Ka / Kd / Ks

- **人话**：3D 表面明暗模型；**Ka** 环境光、**Kd** 漫反射、**Ks** 镜面高光。
- **在本作品里**：录屏旁白 **0.10 / 0.75 / 0.52**（录屏可读字号）；docx 附录可能写 0.12/0.75/0.4——以 `render_spec.json` 为准。
- **相关**：`VolumeScene` 光照；右栏 `task1_lighting_diagram.png`

### log 直方图

- **人话**：横轴 log10(ρ)，纵轴该 bin 内体素**概率质量**（占比×100）。
- **在本作品里**：左栏/右栏 D3 直方图；128 bins；任务三。
- **相关**：`src/histogram/DensityHistogram.tsx`, `precompute.py` — **源码**：[10b](./10b-直方图与D3代码.md)

### brush / 刷选

- **人话**：在直方图上拖拽框选密度区间，系统找出该区间内所有体素并高亮。
- **在本作品里**：任务四；预设 Top 1% / 90–99% / Bottom 1%。
- **相关**：`useAppStore` brushRange；`brushScan.worker` — **源码**：[10c](./10c-刷选与Worker代码.md)

### 相空间（phase space，此处）

- **人话**：此处指「密度值轴 + 统计视图」构成的分析空间，刷选即在此选区间。
- **在本作品里**：§4 标题「相空间交互刷选」。

### MDP / 最大密度投影（Maximum Density Projection）

- **人话**：沿视线取最大 ρ 压成 2D 图；看 filament 平面分布。
- **在本作品里**：右栏金色投影 preview；`BandPreviewCanvas`.
- **相关**：`projection.worker.ts`, `projection_render.py` — **源码**：[10c](./10c-刷选与Worker代码.md) · [10d](./10d-投影空间与录屏组件代码.md)

### P88 亮脊

- **人话**：XY 投影像素亮度第 **88 百分位**以上的像素当作「亮脊」，再反查对应 3D 体素密度区间。
- **在本作品里**：案例 C；ρ∈**[11.23, 12.16]** 与 Top 1% 一致（图14、task2-cases 卡 C）。
- **相关**：`brush_validation.json` → `p88Sweep`

### filament 带（90–99%）

- **人话**：密度在该步 **p90–p99** 之间的体素（约 **9% 体积**），对应纤维「宽尾」。
- **在本作品里**：刷选预设「90–99%」；录屏 task4-brush 第二档。

### KPI（Key Performance Indicator）

- **人话**：仪表盘上醒目数字卡片；如 σ、span、体积%、质量%。
- **在本作品里**：`VideoKpiStrip`、演化三卡、验证 KPI 格。

### LOD（Level of Detail）

- **人话**：远疏近密采样，换性能；体渲染自适应步长。
- **相关**：`adaptiveVolumeSampling.ts`

### wideBoost

- **人话**：16:9 宽屏时相机 zoom 修正，避免宇宙方盒被拉扁。
- **相关**：`fitVolumeCamera.ts`

## 四、工程与工具

### vtk.js

- **人话**：浏览器里做 3D 科学可视化的 JavaScript 库；本作品体渲染核心。
- **相关**：`VolumeScene.tsx`, `vtkConvert.worker.ts`

### D3.js

- **人话**：画 SVG 图表的库；直方图、brush、迷你趋势。
- **相关**：`src/histogram/` — **源码**：[10b](./10b-直方图与D3代码.md)

### Web Worker

- **人话**：后台线程，避免扫 128³ 体素卡死 UI；用于投影、刷选扫描、vtk 轴重排。
- **在本作品里**：早停 **~37–45 ms** vs 全网格 **~282–352 ms**。
- **源码**：[10c §Worker](./10c-刷选与Worker代码.md) · [10a §vtkConvert.worker](./10a-体渲染与VTK代码.md)

### Zustand

- **人话**：React 全局状态库；时间步、刷选区间全站共享。
- **相关**：`src/store/useAppStore.ts` — **源码**：[10c §useAppStore](./10c-刷选与Worker代码.md)

### Vite

- **人话**：前端构建与开发服务器；`npm run dev` / `python run.py` 启动。
- **相关**：`vite.config.ts`

### Playwright

- **人话**：自动化浏览器截图；生成五帧体渲染条带、长卷代表图。
- **相关**：`tools/node/capture_volumes.mjs`

### timeline.json

- **人话**：**所有统计数字的单一真源**；100 步每步 mean/std/分位数/直方图等。
- **相关**：`public/stats/timeline.json`；`precompute.py` 生成

### z-fast / x-fast（存储顺序）

- **人话**：磁盘与刷选用 **z 最快**；vtk 体渲染要 **x 最快**；Worker 中间转换。
- **在本作品里**：附录 3.4 表9；`nyxLoader.flatIndex`, `Z_TO_VTK` 查表

### `?record=1`

- **人话**：录屏模式 URL 参数；隐藏导航杂项、放大字号、禁用无关点击放大。
- **在本作品里**：`useVideoScene.ts` → `recordMode`
- **相关**：`VideoDashboard.tsx` → `html.video-record-mode`

### scene（录屏场景）

- **人话**：11 个预置布局页，如 `scene=task4-brush`；每页对应旁白一行。
- **相关**：`src/video/sceneRegistry.ts`

## 常见评委问答（FAQ）

> **实现类追问**（刷选联动、Worker、timeline 从哪来等）→ [10 答辩代码讲解 §7](./10-答辩代码讲解.md#7--代码类评委-faq) · 源码见 [10a](./10a-体渲染与VTK代码.md)–[10e](./10e-Python配图代码.md)

### Q1：五帧条带和网页体渲染颜色不一样？

**A**：条带用 **capture 专用 Evolution Profile**，每帧 TF 不同，只讲**形态**；交互页与录屏用**全局 TF**，定量与答辩演示以交互页为准。见 [00 章](./00-阅读指南.md)、[04 §0](./04-Word正文逐章解读.md#0--系统概览)。

### Q2：Moran's I 上升了，能说明团块化吗？

**A**：作**描述性辅证**；bootstrap 子块抽样下增量**未达 2σ**，不作显著性主证。主证是 σ 与 p99−p01 百步曲线。

### Q3：精确率 27.6% 是不是刷选错了？

**A**：不是。离线用 filament **几何代理**对比**密度 Top 1% 集合**：召回 **100%**（脊线都被选中），精确率 27.6% 表示分位集合**更宽**——密度尾 ⊃ 脊线，符合「先按统计选再看空間形态」的设计。误报率 72.4% 在 docx 表16 与 §4 已说明。

### Q4：拖拽刷选后 KPI 体积占比很小？

**A**：UI 上 **早停采样**（stride=2, maxPoints=8000）只统计抽样体素数；**体渲染/投影高亮仍对全场**按密度阈值着色。宽区间 p50–p99 显示可仅 ~0.78% 真值。

### Q5：有没有做 Lyα 森林？

**A**：**没有**完整辐射传输。§5.5 仅 2000 条 +z 视线列平均 ρ 的 PDF **代理**，说明对比度趋势与模拟一致，**不能**与真实 QSO 谱定量比对。

### Q6：为什么没有暗物质 / AMR？

**A**：赛题 .dat **仅重子气体均匀 128³**；无 DM 坐标、无 AMR 层级元数据。§5.4、§5.6 边界说明。

### Q7：128 bin 直方图锯齿？

**A**：log 域宽动态范围 + 多峰结构；附录 5.3 对比 64/128/256 bins，默认 128 为精度与平滑折中。

### Q8：代码开源吗？

**A**：按赛题与队方提交要求；录屏第 11 段口播「GitHub 仓库 NyxViz」——以实际提交链接为准。

## 出问题怎么办

| 现象 | 排查 |
|------|------|
| 体渲染全黑 | 确认 `Nyx/` 数据存在；控制台 WebGL 错误 |
| 数字与 Word 不符 | 重跑 `npm run precompute` + `test:report` |
| 录屏字号太小 | URL 必须带 **`record=1`** |
| 点击缩略图卡死 | 已修复：EvolutionThumbnails 内 zoom 与 button 冲突 |

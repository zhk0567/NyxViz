# 任务二：宇宙密度演化规律归纳

## 结构形成
模拟显示物质由近乎均匀分布（t=0 分位跨度 2.098）在引力作用下逐步团块化；t=99 分位跨度增至 2.414，表明密度涨落幅度显著增大，宇宙网 filaments 与节点结构形成。

## 星系际介质（IGM）
绝大部分体积占据低密度区间（直方图左峰），高密度尾部占比约 1.00%（≥p99），对应 IGM 中稀疏重子汇聚通道。

## 可视化价值
体渲染提供全局形态直觉；统计直方图量化分布漂移；交互刷选将高密度尾与空间节点对应，实现“假设—证据”闭环，降低逐体素盲目探索成本。

# 灰度线框（Wireframe）检查清单

在填充配色与真实图表之前，用 **3840×6480** 画布仅绘制矩形与文字标签。目标：验证 §4 高度分配与 §5–§10 坐标，避免做到一半整体推翻。

参考：[`LAYOUT_SPEC.md`](./LAYOUT_SPEC.md) · 参考图 [`reference/cosmic_web_poster_reference.png`](./reference/cosmic_web_poster_reference.png)

---

## 画布

- [ ] 3840 × 6480，背景 `#03030A` 或 `#1a1a1a`（线框阶段可用浅灰 `#222` 区分区块）
- [ ] 顶/底各 190 px 留白可见
- [ ] 左右 120 px 边距可见

## 通过标准

1. 六段高度之和 = **6100**，加上下 190 = **6480**。
2. 无元素超出 X∈[120, 3720]（主内容）除非色标贴右缘 3600+40≤3840。
3. 与参考图**扫一眼**结构一致（不核对示意数字）。
4. 团队签字/备注后，再进入 Production（`npm run figures` 按 Spec 重排）。

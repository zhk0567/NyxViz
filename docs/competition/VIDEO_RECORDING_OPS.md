# NyxViz 录屏 · 旁白同步操作表

> 与 [`VIDEO_NARRATION_TTS.txt`](./VIDEO_NARRATION_TTS.txt) **11 行一一对应**（一行 = 一个 `?record=1&scene=` 页面）。  
> 录屏地址见 [`VIDEO_SCRIPT.md`](./VIDEO_SCRIPT.md) §2。  
> **原则**：除标注「点击 / 拖拽」外，其余均为 **鼠标指向对应区域、稍停 1–2 秒** 即可。

---

## 通用（每段开头）

| 时机 | 操作 |
|------|------|
| 打开对应 URL 后、开 OBS **前** | 等中栏体渲染出图（或该页主图加载完）；顶栏确认 **t=99**（**形态演化段除外**） |
| 段与段之间 | 换 URL → 等新页稳定 → 再开录 |

**仅 3 段需要动手**：形态演化（切步）、相空间刷选（预设 + 拖拽 + 清除）、综合发现（放大卡片）。其余 8 段指屏讲解即可。

## 2. 整体画布

| 项 | 值 |
|----|-----|
| 成品尺寸 | **3840 × 6480 px** |
| 用途 | 4K 宽、纵向长卷、比赛大屏可滚动 |
| 宽高比 | **1 : 1.6875**（高 ÷ 宽 = 1.6875） |
| 内容区高度 | 6100 px（六段之和） |
| 上下留白 | 各 **190 px** → 190 + 6100 + 190 = **6480** |

### 坐标系约定

- **画布坐标**：原点左上角，单位 px，范围 X∈[0,3840]，Y∈[0,6480]。
- **内容坐标**：Y∈[0,6100]，对应画布 Y = **190 + y_content**。
- 下文「Y=」未注明时，指**内容坐标**；换算画布：`Y_canvas = 190 + Y_content`。

## 3. 栅格系统

| 项 | 值 |
|----|-----|
| 列数 | **24 列** |
| 左右边距 | **120 px** |
| 列槽（gutter） | **40 px** |
| 内容区宽度 | 3840 − 240 = **3600 px** |
| 单列宽度 | (3600 − 23×40) / 24 ≈ **111.67 px** |

列 `i`（0-based）左缘 X：

```text
X(i) = 120 + i × (111.67 + 40)
```

跨 `n` 列宽度：

```text
W(n) = n × 111.67 + (n − 1) × 40
```

> 实现时可用 `layout_spec.col_x(i)` / `layout_spec.span_w(n)`，避免手算误差。

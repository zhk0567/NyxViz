这是 NyxViz 答辩录屏旁白；量化方法与图表详见提交作品说明。系统面向 Nyx 128 立方、100 时间步重子气体密度，按任务一至四演示。三栏布局：左栏为预计算五帧直方图与 σ、≥p99 体积占比、p99−p01 分位跨度等百步趋势；中栏 vtk.js GPU 光线投射；右栏当前步直方图、刷选与 XY 投影。顶栏 t=0…99，默认 t=99。

任务一，传递函数与光照。cosmic 传递函数在 log10 域将密度 p01 至 p99 范围 8.346 到 10.760 映射为颜色与不透明度，以压缩 IGM 大动态范围。不透明度在归一化密度的七个位置上，α 从 0 逐渐增至 0.95，以防 IGM 雾屏、突出 filament。Phong 光照 Ka/Kd/Ks 为 0.12、0.75、0.4，Ks 提供 filament 脊线高光；主光源方向为东北上方，辅光 RGB 0.55、0.75、1.0、强度 0.3 补充 void 照明；sampleDistance 等于 0.65。请点击 t=0，观察均匀雾状；点击 t=25，丝状初现；点击 t=50，连通性明显增强；再点 t=75 与 99，宇宙网成形；t=99 时 σ 等于 0.4983，p99 等于 10.7601。

任务二，演化规律与可视化价值。核心规律是引力团块化与密度两极化。量化上：第一，线性密度 σ 由 0.4318 升至 0.4983，上升 15.4%；第二，p99−p01 分位跨度 2.098 增至 2.414，上升 15.1%；第三，p99.9 相对 t=0 抬升 1.009 倍。void 方面：由于子体积无全宇宙平均密度标定，无法使用常见的过密度 void 定义，因此改用统计阈值。以 t=0 时的 p10 为阈，按 p10 定义初始占比即为 10.00%，末期升至 24.69%；以 p01 为阈，由 1.00% 升至 6.18%，低密度尾扩张更明显。可视化价值：案例 A，若无百步曲线，易只看 t=0 与 t=99 挑帧叙事；案例 B，Top 1% 体积 1.00% 却承载 1.19% 质量，刷选呈 filament 丝状；案例 C，投影图像素值的第 88 百分位数 P88 提取亮脊，反查得密度范围 11.23 到 12.16，与 Top 1% 一致。空间统计辅证：Moran 的 I 0.9276 升至 0.9361，ξ 在 r=1 由 0.855 升至 0.871，增量均未达到两倍 bootstrap 标准差，Moran 的 I 的 bootstrap 标准差约 0.014、ξ 的约 0.035，仅作趋势描述。

下面从密度分布随时间的偏移来补充分析团块化规律。任务三，密度时序统计。密度动态范围大，线性分箱易淹没低密度细节；log 等距直方图能更好展示 void 与 filament 的差异。我们对 100 个时间步分别构建 log 直方图并分析演化偏移；录屏页左栏展示五代表步叠加与百步趋势，完整序列见作品说明。128 分箱，边界 7.753 到 14.523；主峰在中低密度 IGM 区，右尾增厚。128 bins 为默认，64 与 256 bins 的 CDF L∞ 误差不超过 0.0012。≥p99 体积占比 1.00%，与任务二 Top 1% 一致，对应最亮 filament 与 node。

任务四，相空间刷选。右栏为当前步 log 直方图。确认 t=99，点击 Top 1%，ρ ≥ 10.7601，体积占比 1.00%，质量占比 1.19%，体渲染与投影高亮。再点 90–99% 纤维带与 Bottom 1%。预设按钮 KPI 直接采用 timeline 精确分位数值。此外，用户也可在直方图上手动拖拽框选自定义区间，此时通过早停采样估算，显示体素数可能偏低，例如 p25–p75 区间仅为真值的约 0.76%，Top 1% 早停采样到的体素数占真值的约 12.7%，仅影响 KPI 读数；体渲染与投影高亮基于密度阈值对全体素进行高亮，不受早停采样影响。点击清除按钮，清除高亮。

底部四张发现卡：第一，宇宙网五帧演化；第二，密度两极化；第三，1.00% 体积承载 1.19% 质量；第四，Top 与 Bottom 1% 投影双向一致。点击可放大。

综上，NyxViz 以体渲染、百步统计与刷选形成统计到空间闭环。开源仓库 github.com/zhk0567/NyxViz，更多技术细节见作品说明文档。

NyxViz 是一套面向 Nyx 一百二十八立方格、一百步重子气体密度场的 Web 可视化分析系统，主旨是把时序统计、体渲染与相空间刷选连成从数字到结构的解读闭环。三栏布局：左栏五步直方图叠加与 sigma、p99 及以上占比、分位跨度趋势，中栏体渲染，右栏刷选预设与密度投影，默认第 99 步。
传递函数与光照。宇宙学色标在 log10 域将 p01 至 p99 映射为颜色与不透明度，对应 8.346 至 10.760。七处 alpha 由 0 增至 0.95，突出纤维、抑制雾屏。冯氏光照系数 0.10、0.75、0.52，主光东北上方、辅光 Fill 补 void 区；右栏为 Phong 主辅光示意图。
形态演化。此处依次切换至第 0、25、50、75、99 步，可见宇宙网由均匀涨落到大尺度纤维成形；第 99 步 sigma 0.4983，p99 10.7601。
演化量化。左栏叠加直方图与三卡 KPI：sigma 0.4318 升至 0.4983，升 15.4%；p99 减 p01 跨度 2.098 到 2.414，升 15.1%；p99.9 抬升 1.009 倍。右栏四图给出分位跨度、sigma、高密度尾体积占比与偏度 skew 的百步曲线，右尾体积占比稳定约 1%，偏度由 0.716 缓升至 0.718。
void 双阈值。统计阈值 p10 体积占比由 10% 增至 24.69%，p01 由 1% 增至 6.18%，刻画低密度 void 区随团块化扩张。
案例 A、B、C。A 用百步曲线避免挑帧；B 为 Top 1% 高密区，体积 1%、质量 1.19%，中栏体渲染与投影同步高亮；C 沿 P88 亮脊反查，密度 11.23 到 12.16。
空间统计。左栏四图依次为 Moran I、xi 在 r 等于 1 处、分形维 D 与超额峰度 kappa 减 3 的时序，下方宽图为 xi 剖面与子块蒙特卡洛一倍标准差带。右侧辅证 Moran I 0.9276 升至 0.9361，xi 0.855 到 0.871，并附 bootstrap 置信区间；增量均未达两倍抽样标准差。
密度时序。对数直方图呈现 void 与纤维差异，左栏五步叠加与分箱敏感性读数，右栏主峰漂移与 sigma、偏度、分位跨度趋势图；128 分箱，CDF 最大偏差不超过 0.0012，p99 及以上体积 1%，对应最亮纤维。
相空间刷选。在第 99 步选取 Top 1%，密度不低于 10.7601，体积 1%、质量 1.19%，体渲染与投影同步高亮；继而切换 90 至 99% 纤维带与 Bottom 1%，并演示直方图拖拽框选；KPI 由早停采样给出，高亮仍覆盖全体素，最后清除选区。
验证与早停。左栏三图呈现阈值对比、自定义 KPI 误差与 Top 1% 早停召回，右栏 KPI 面板给出离线召回 100%、精确率 27.6%；p25 到 p75 早停覆盖约 0.76%，Top 1% 采样约 12.7%；早停 37 毫秒，全网格 282 毫秒。
综合发现。四张发现卡概括宇宙网演化、两极化、1% 体积与 1.19% 质量、Top 与 Bottom 1% 投影一致，各卡均支持放大细读。综上，NyxViz 以体渲染、百步统计与刷选形成统计到空间闭环，代码开源，见作品说明与 GitHub 仓库 NyxViz。
